# Security — Revenue Backlog Automation

- Keep file-share, database, and cloud credentials outside source control.
- Validate inbound files before processing.
- Restrict access to project and customer-level financial detail based on business need.
- Preserve source files or source-row references for traceability.
- Store FX tables and mapping tables in controlled locations with documented ownership.
- Separate manual overrides from original input values.
- Do not publish real project, entity, customer, backlog, or revenue information in portfolio artifacts.
- Use synthetic examples for all public demonstrations.
